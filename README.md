# OTT 콘텐츠 통합 검색 서비스
![couchpotato](https://github.com/user-attachments/assets/b6d4d6ff-b648-429b-838a-b20b8ca0080c)

<br>

## 프로젝트 소개
- 여러 OTT 플랫폼의 콘텐츠 정보를 통합하여, 사용자들이 한 곳에서 간편하게 검색하고 관리할 수 있는 서비스입니다
- OTT 플랫폼별 콘텐츠 랭킹(TOP 10)의 정보를 제공합니다.
- 콘텐츠 정보를 검색하고, 그에 대한 리뷰를 등록할 수 있습니다.
- 리뷰 작성시 캘린더를 통해서 날짜별 리뷰보기, 전체 리뷰 보기 등으로 관리할 수 있습니다.
- 콘텐츠 N회차 리뷰 작성 시, 회차 정보를 제공합니다.
- 다양한 유저들을 팔로우하고, 친구들이 감상한 콘텐츠 및 리뷰를 볼 수 있습니다.

## 역할 분담
### 🥔 선푸름

- **기능**
  - 리뷰 작성 시 캘린더와 연동(리뷰 캘린더), 날짜별 리뷰 보기, 월별 리뷰 모아보기
  - 리뷰 수정 및 삭제, 콘텐츠 N회차 리뷰 작성 시에 회차 정보를 제공
  - 팔로우의 리뷰 캘린더 및 리뷰 보기
  - 전체 CSS
<br>

### 🥔 김호영

- **기능**
  - 로그인, 회원가입, 마이 페이지, 비밀변호 변경, 로그아웃
  - 프로필 설정 및 수정(이미지 업로드)
  - 유저 아이디 중복 검사
<br>

### 🥔 박유은

- **기능**
  - 팔로잉 & 언팔로우, 팔로워, 사용자 전체 검색
  - 팔로잉 및 팔로워 수를 카운트하여 버튼에 표시
  - 팔로우 모달창
<br>

### 🥔 조성현

- **기능**
  - TMDB API 사용해서 콘텐츠 정보 가지고 오기
  - 각 플랫폼별 랭킹(TOP 10), 컨텐츠 검색, 컨텐츠 상세 보기
  - 리뷰 작성, 내 리뷰보기, 콘텐츠별 리뷰 보기, 팔로우의 리뷰 보기
<br>
